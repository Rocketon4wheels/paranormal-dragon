How to get a Gmail App Password
1Go to myaccount.google.com/security and enable 2-Step Verification if not already on.
2Search for "App passwords" in your Google account, or go to myaccount.google.com/apppasswords

Stripe Payments
Accept Oracle, Investigator, and Chronicler subscriptions
Setting up Stripe — step by step
1Go to dashboard.stripe.com. If you don't have an account, create one free. You don't need to verify your business before testing.
2In the top-left, make sure you are in Test mode (toggle in sidebar). This lets you test without real money.
3Go to Developers → API keys. Copy your Secret key (starts with sk_test_ for test mode).
4Go to Products → Add product. Create three products:
• The Oracle — $9/month recurring
• The Investigator — $19/month recurring
• The Chronicler — $49/year recurring
After saving each, click the price to copy its Price ID (starts with price_).
5Go to Developers → Webhooks → Add endpoint.
URL: https://api.strangenessis.com/stripe/webhook
Select events: checkout.session.completed, customer.subscription.deleted, customer.subscription.updated
After creating, click "Reveal signing secret" and copy it (starts with whsec_).
Note on verification
Stripe will ask to verify your business before enabling live payments. That's fine — start in Test mode, enter all the keys, and test with card 4242 4242 4242 4242 (any future date, any CVC). Switch to live keys once you're ready to accept real money.

Google Analytics 4
Track page views, Oracle sessions, pricing clicks, and conversions
Setting up GA4
1Go to analytics.google.com → Start measuring → Create a property for strangenessis.com.
2Choose Web as the platform. Enter strangenessis.com as the URL.
3After creating, copy your Measurement ID from the top of the page — it looks like G-XXXXXXXXXX.
4To get the API Secret for server-side tracking: Admin → Data Streams → click your stream → Measurement Protocol API secrets → Create. Copy the secret value.
Optional. Without this, only frontend page views are tracked. With it, member signups, purchases, and Oracle sessions are also tracked server-side.
Also update your HTML pages
After saving, you also need to replace G-XXXXXXXXXX with your real Measurement ID in the <meta name="ga-id"> tag in every HTML file, then redeploy. This wizard handles the server side — the frontend update requires a redeploy.

Tawk.to Live Chat
Free live chat for The Investigator tier — completely optional
Setting up Tawk.to (takes 5 minutes)
1Go to tawk.to and create a free account.
2Add a new property for strangenessis.com. It will ask you to verify the domain — you can skip that step for now. The chat widget will still work.
3Go to Administration → Chat Widget. Look at the embed code — your IDs are in this part of the URL:
https://embed.tawk.to/YOUR_PROPERTY_ID/YOUR_WIDGET_ID
4Copy those two IDs and paste them below. Tawk.to does NOT require domain verification to function — only to show in their dashboard stats.
